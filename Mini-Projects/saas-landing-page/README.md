# AIFlow Landing Page

A professional SaaS product landing page for a fictional AI startup called "AIFlow". Designed to be modern, responsive, and showcase best practices in web development without relying on heavy frameworks.

## Technologies Used
- HTML5
- CSS3 (Vanilla, custom properties, Flexbox, CSS Grid)
- Vanilla JavaScript (DOM manipulation, event listeners)
- Inline SVGs (No external image dependencies)

## Folder Structure
```text
saas-landing-page/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── .gitkeep
└── README.md
```

## How to Run Locally
1. Clone this repository or download the files.
2. Navigate to the `saas-landing-page` directory.
3. Open the `index.html` file in your preferred web browser. You can just double-click `index.html` or drag and drop it into a browser window.
4. (Optional) For a better experience (to avoid CORS issues or if you add external assets later), serve it using a local development server like Live Server in VS Code, or Python's `http.server` (`python -m http.server`).

## Features
- **Responsive Design**: Looks great on Desktop (1920px), Tablet (768px), and Mobile (375px).
- **Interactive Navbar**: Sticky header with a hamburger menu for mobile devices.
- **Hero Section**: Engaging copy with CSS gradient background and floating SVG animation.
- **Features Grid**: Highlighted key offerings with hover effects.
- **Pricing Plans**: Tiered pricing structure with a highlighted "Most Popular" option.
- **Testimonials**: Customer quotes and avatars.
- **FAQ Accordion**: Clickable questions that reveal answers via Vanilla JS.
- **Footer**: Organized links and branding.
