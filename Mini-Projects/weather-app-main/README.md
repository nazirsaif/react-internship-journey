# 🌦️ Weather App

A modern and responsive Weather Application that provides real-time weather information for any searched location. The application fetches live weather data from an external API and displays important details like temperature, humidity, wind speed, and weather conditions in a clean and user-friendly interface.

## 📌 Features

✨ **Real-Time Weather Updates**
- Search any city and get current weather information instantly.

🌡️ **Temperature Details**
- Displays current temperature.
- Shows weather conditions.
- Provides location-based weather information.

💨 **Weather Information**
- Temperature
- Humidity percentage
- Wind speed
- Weather description
- City and country details

📱 **Responsive Design**
- Fully optimized for desktop, tablet, and mobile devices.

⚡ **API Integration**
- Fetches live weather data using REST API.
- Handles user requests and displays accurate weather results.

## ⚙️ Installation & Setup

Follow these steps to run this project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/nazirsaif/weather-app.git
```

### 2. Navigate to Project Directory

```bash
cd weather-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Create Environment Variables

Create a `.env` file in the root directory and add:

```
WEATHER_API_KEY=your_api_key_here
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```

### 5. Start the Application

```bash
npm start
```

The application will run on:

```
http://localhost:5000
```

## 🎯 How It Works

1. User enters a city name.
2. Application sends a request to the weather API.
3. API returns real-time weather information.
4. Weather data is processed and displayed on the interface.
